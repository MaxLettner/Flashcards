# Flashcards

Simple Android flashcard app (Kotlin + Jetpack Compose).

- Add, edit and delete cards (tap a card to edit it)
- Spaced repetition (Leitner boxes: 1, 2, 4, 8 … days)
- Daily reminder notification at a time you pick (Settings ⚙). It's only sent if cards are due.

Build: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk` (needs the Android SDK, API 35).
